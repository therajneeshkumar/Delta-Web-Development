# Teminal

- A text input and output environment.
- Used to perform textual commands for several operations.

---

## Different Terms

- **Command Line :** any interface that is used by external textual commands (ger. ***Windows*** centric).
- **Terminal :** This is a type of command line (gen. ***Mac*** centric).
- **Console :** A command line interface used to work with your computer.
- **Shell :** A programm running on terminal.
- **Bash :** A popular shell on mac OS / Linux.
- **Z-Shell :** Another shell (default).

---

## Basic Commands

- **`ls`** : List Files (Show my files).
- **`pwd`** : Print Working Directory (Where am I?).
- **`clear`** : Clear screen.

---

## Navigation

- Inside and Outside Directories
- **`cd`** Change Directory
- ***`cd Foldername`** : Used to move inside a directory.
- ***`cd..`*** or ***`cd ..`*** : Used to move outside a directory (i.e. Back Button).

### Paths in Navigation

- Absolute & Relative Path
- **`cd folder1/folder2`** : (relative path => Relative to current location)
- **`cd /users/rootDirectory/folder1/folder2`** : (absolute path)
- ***`/`*** : root directory
- ***`/`*** : root directory

---

## Making Directories

- **`mkdir`** or ***`md`*** : Both are used to **Making Directory**.
- ***`mkdir folderName`*** or ***`md folderName`***

---

## Flags

- Flags are characters that we pass with commands to modify their behaviour.

### Manual Command

- **`man commandName`** : Used to know about the command information.

- **`man ls`** : Gives info about ***ls*** command.
- **`man mkdir`** : Gives info about ***mkdir*** command.

### With Flags

- ***`ls -l`*** : Provide additional information about directories and files.
- ***`ls -a`*** : Include directory entries whose names begin with a dot. Hidden files also start with a dot.
- ***`ls -la`***

---

## Touch Command

- Change file access and modification times of each FILE to the current time.
- Used to create empty files.
- Type file name with required file extension.
- ***`touch fileName.extension`***

---

## Deleting Files and Folders (Senstive Commands)

- **`rm`** : Removes files
- **`rmdir`** : Removes empty folders
- **`rm -rf`** : Removes any folders
  - ***rf :*** Recursive Force [remove with force]  
    r => Recursive Delete & f => Forced Delete
